# HW3P2 — Spring 2021 clean handout reconstruction

The official S21 HW3P2 distribution specified the data files, phoneme mapping,
and submission format, but did not publish a full Python starter framework.
This directory has therefore been reduced to that open-ended handout style.

Preserved course materials:

- `hw3p2_writeup.pdf`
- `utils/phoneme_list.py`

Your local work deliberately retained:

- `models.py`

`hw2_classification.py` is now an empty, task-oriented scaffold. It contains no
completed data loading, training, decoding, or submission implementation.
